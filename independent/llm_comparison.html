Independent LLM modelling comparison

Three pipelines, each designed by a different model and run on the same data. Claude built its pipeline in this session. GPT-6 Astra and Gemini each designed theirs independently through OmniRoute, starting from their own earlier EDA and the task brief only. They never saw Claude's features, models or scores. Claude ran their scripts locally and reported the raw outcomes back without advice. Every final model is re-scored below with the same code, on the same 6,941 training accounts.

The validation schemes differ, so the "honest" level differs too. GPT-6 Astra used fully nested CV, where every tuning and pruning choice was made inside inner folds. Claude tuned once on one repeat and chose its pruning after seeing results, so its number is mildly optimistic. The Kaggle public score is the only check none of them saw.
