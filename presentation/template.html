How to read this.

  2. The A+B+C average scores highest (pooled 0.9825, hard group 0.905), but only 0.0004 above logistic regression alone. That's well inside the fold SD (~0.005), so the two are effectively tied.

4 · The 25 features (lecture method, W1 s34)

  1. Null threshold: drop features more than 50% missing (W1 s34). That removes 12, mostly sub_last_*/sub_mean_*, which only exist for past subscribers.
  2. Filter: rank by mutual information with the label (W1 s31–32), then drop near-duplicates (|Spearman| ≥ 0.95 with a stronger feature) to keep 35 candidates. This removes 17 redundant copies of the same "recent subscriber" or "donor" signal.
  3. Embedded: random-forest importance picks the final 25 (W1 s33). The two ID features are always kept.
  4. No leakage: this runs inside each CV training fold, never on validation rows (W2_H1 s16, s19). The table is a full-data preview; "stable" counts how many of 5 folds picked the feature.
Things to know. (1) Random-forest importance favours continuous features, so four overlapping distance features made the cut while compact flags like don_2013_any appear in only 2 of 5 folds. If you prefer, distances can be capped at one (geo_km_nearest_venue) to free 3 slots. (2) Dropping features over 50% missing follows the lecture rule but also drops package/seat details for past subscribers. A justified exception is possible; the lecture-faithful version is the default.

6 · Cross-validation and ensemble plan

  • Same folds for every model: repeated stratified 5-fold (5 repeats = 25 fits per config), stratified on label × subscribed-in-2013-14. Each fold then holds ~10 of the hard new/lapsed positives.
  • Score on pooled out-of-fold AUROC averaged over repeats, not single-fold means: fold-to-fold spread is ~0.04, too noisy to tell 0.96 from 0.97. Models are compared pairwise on identical splits.
  • Tune on one 5-fold split, confirm on all 5 repeats. The top 3 configs per model get the full 5×5. Ties go to the simpler model.
  • Report two numbers per model: overall AUROC and AUROC on the hard group (accounts that did not subscribe in 2013-14). Gains there decide the top of the leaderboard but barely move the overall number.
  • All preprocessing fitted inside each training fold (imputation, scaling, encoders). No oversampling, since AUROC doesn't need balanced classes.
  • Rare signals (multiple.subs: 12 recent subscribers; 2014 gifts: 31 non-subscribers) stay as ordinary features. Regularisation and leaf-size limits stop models from memorising them.
  • Ablations, decided in advance: with vs without the ID-cohort group; with vs without don_first_in_2014; normal vs strict (pre14_) donation totals. A feature stays only if its gain beats the fold noise.
  • Optional time-shifted check: rebuild features as of 2012-13 and predict 2013-14 across all 19,833 accounts (982 positives). The pipeline automatically drops donation and ID features here because they can't be shifted. This is a stress test, not the selection metric.
  • Ensemble: start with an equal-weight average of the three models' out-of-fold probabilities. Learned weights or stacking only if evaluated with nested CV. Leaderboard submissions are sanity checks (10/day), not a tuning signal.
  • Cost: 84 configs × 5 folds, plus 9 finalists × 25 fits, on 6,941 rows: roughly 5–15 minutes on a laptop, with random forests the slowest.

7 · Decisions for you before running

  1. Tuning design (the one real trade-off):
    (a) Tune on one 5-fold split, then score the frozen winners on all 5×5: ~20–30 min total, slightly optimistic scores. This is v2 and is recommended.
    (b) Fully nested CV, retuning inside every outer fold: the textbook-unbiased version (W2_H1 s16–19), ~2–3 h, mostly random forest.
  2. Model line-up: zero-rule + heuristic + A (L1/L2 logistic) + B (random forest) + C (MLP ensemble). Add SVM + Platt scaling as an optional 6th?
  3. Features: 25 chosen in-fold, including the 2 interactions and the 2 ID-cohort features. Cap the four distance features at one?
  4. Missing-value rule: the lecture rule (drop > 50% missing), or an exception for past-subscriber details?
  5. Final submission: the best single model, or the A+B+C average only if it beats it on paired out-of-fold results.
